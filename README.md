🚀 BION – Frontend (Flutter)

BION is a modern mobile application built using Flutter, focused on clean UI, smooth navigation, and scalable architecture.
This repository contains the frontend codebase of the BION app.

📱 Tech Stack

Flutter (Dart)

Material UI

State Management: (add later – Provider / Riverpod / Bloc)

REST API integration (Backend handled separately)

📂 Project Structure
lib/
 ├── main.dart
 ├── screens/        # All app screens
 ├── widgets/        # Reusable UI components
 ├── services/       # API & logic layer
 ├── models/         # Data models
 └── utils/          # Constants, helpers


This structure keeps the code clean, readable, and scalable.

⚙️ Setup Instructions
1️⃣ Clone the repository
git clone https://github.com/your-username/bion-frontend.git
cd bion-frontend

2️⃣ Install dependencies
flutter pub get

3️⃣ Run the app
flutter run


Make sure you have:

Flutter SDK installed

Emulator or physical device connected
